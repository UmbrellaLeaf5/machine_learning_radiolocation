# Правила работы в репозитории

## Неизменяемый план

- `TODO.md` **ЗАПРЕЩЕНО РЕДАКТИРОВАТЬ** после создания: не отмечать выполненные пункты, не добавлять статусы и не переписывать план. Прогресс фиксировать отдельными коммитами по завершении каждой задачи. В одном коммите — результат одной завершённой задачи, после проверки; не коммитить посторонние незавершённые изменения.

## Ноутбук `Домашние задания/hw_01/HW1.ipynb`

- Ячейки с пометкой **«не менять»** не редактировать ни при каких условиях. Особенно не трогать ячейки с `# fmt: off` / `# fmt: on`: их код и эти директивы сохранять. Для контроля сравнивать защищённый код с `HW1_starter.ipynb` (директивы форматтера, уже находящиеся в `HW1.ipynb`, сохраняются). Не редактировать исходный starter.
- В **своих кодовых ячейках** использовать эталонное обрамление `# ! -------------------------------------------------- !` сверху и снизу. Не добавлять эти разделители в защищённые ячейки, не менять имеющиеся разделители и не запускать скрипты массовой разметки. Это требование не отменяет запрета трогать чужие/защищённые ячейки.
- Полное обучение и полный прогон выполнять только при обоснованной уверенности после точечных проверок, что изменение улучшит **всю цепочку** от данных и обучения до выбора весов и автономного `Submission`. Не переобучать ради правок оформления, диагностики или локальных изменений: сначала проверять на сохранённых checkpoint и без полного обучения.
- Использовать проектный `.venv`; сохранять исходный train/val, сиды, совпадающие геометрические аугментации пары. Отбирать лучшую модель и настраивать гиперпараметры только по val; не использовать закрытый тест. Loss и отбор негативов писать вручную; финальная псевдосиамская сеть должна иметь раздельные веса ветвей.
- Не очищать сохранённые выводы при сдаче: все кодовые ячейки должны выполняться сверху вниз без ошибок, графики и таблицы сопровождаться русскими выводами. Указывать размер галереи при Recall@K; не путать N=2100 и N=1000.
- По ТЗ интерфейс `Submission` должен работать **сам по себе** из одной ячейки с импортами, моделью и предобработкой, без зависимости от ранее выполненных ячеек. Проверять в чистом процессе и штатной самопроверкой, не меняя защищённый код самопроверки; веса передаются отдельно от `first_run_metrics.json`.
