## Слайд 4

Постановка задачи SAR-Opt Matching
Термины:
Opt (optical images, оптические изображения) —  изображения видимого или инфракрасного диапазона.
Matching (сопоставление) — задача поиска и установления соответствия между объектами из разных наборов данных на основе определённых критериев.
Матчер — алгоритм, выдающий пары соответственных точек.
Keypoint (ключевая точка) — характерная точка на изображении, отличающаяся по какому-либо критерию (зачастую граничная или угловая).
Гомография — проективное преобразование, сохраняющее прямые линии. Задаётся матрицей 3х3, точно описывает отображение плоскости в плоскость. Укорочение и наложение гомографией не описываются.

## Слайд 6

Постановка задачи SAR-Opt Matching
Цель: Найти соответствия между SAR и Opt изображениями одной и той же местности.
Варианты постановки задачи:
Patch matching. Осуществить сопоставление между наборами из  SAR изображений и  Opt изображений одного физического размера. Для каждого SAR-изображения найти соответствующее Opt-изображение из набора; при необходимости уточнить взаимное положение.
Image registration. Осуществить сопоставление между наборами из  SAR изображений и  Opt изображений разного физического размера. Меньшее из изображений необходимо наложить на большее и указать для него матрицу гомографии.

Классические методы решения задачи

Обнаружение ключевых точек на обоих изображениях:
SAR: адаптированные детекторы (SAR-SIFT + SAR-Harris);
Opt: стандартные детекторы (SIFT, SURF, ORB).

Сопоставление по расстоянию между ACF-дескрипторами.
Отсев ложных соответствий через RANSAC и получение матрицы гомографии.
Другие варианты:
Поиск взаимной информации (Area-based методы)
структурные дескрипторы (HOPC, CFOG, RIFT).

## Слайд 15

Классические методы решения задачи
Дополнительные термины:
Inliers — пары точек, которые согласуются с гомографией H по заданному критерию. Например, если перенести точку SAR по правилу H, она попадёт не дальше чем в 3 px от своей пары на Opt.
Outliers — все остальные, то есть ошибки преобразования. Например, угол одной крыши сопоставился с другим похожим углом, перекрёсток — с соседним перекрёстком.

## Слайд 16

Классические методы решения задачи
RANSAC (Random Sample Consensus) оценивает преобразование по соответствиям на основе случайного выбора.
Случайно выбрать минимальный набор соответствий (для гомографии — 4 пары точек).
По нему вычислить гомографию H.
Найти количество inliers.
Повторить N раз, оставить H с максимумом inliers и пересчитать её только по всем inliers.

## Слайд 38

Метрики качества
Поиск пары: Recall@K и MRR
Для каждого SAR сортируем все M кандидатов Opt по расстоянию между эмбеддингами, тем самым получаем ранг (место) истинной пары в этом списке.
Recall@K (Top-K accuracy) — доля SAR, у которых ранг ≤ K. Обычно приводят K = 1, 5, 10.
MRR — среднее значение  для всех SAR. Одно число, наказывает за пары, уехавшие далеко по списку.
Размер M должен учитываться всегда: Recall@1 среди 100 и среди 1000 кандидатов несравнимы.

## Слайд 39

Метрики качества
Верификация: это одно и то же место?
ROC-AUC — отражает то, насколько случайная истинная пара ближе случайной ложной. Не зависит от порога; чем больше, тем лучше.
FPR95 — доля ложных срабатываний при пороге, который находит 95% истинных пар. Это стандарт в статьях про сопоставление; чем меньше, тем лучше.
Precision / Recall / F1 — при конкретном рабочем пороге. Порог выбираем на валидации, метрики сообщаем на тесте.

## Слайд 40

Метрики качества
Метрики соответствия точек
Нужна истинная геометрия . Пара точек (p, q) считается верной, если  (обычно ε = 3 px).
Количество правильных сопоставлений (NCM, number of correct matches) — сколько верных пар. Если их меньше четырёх — гомографию не построить вообще.
Доля правильных сопоставлений (CMR, correct matching ratio) — . Это доля inliers w из формулы RANSAC: чем она выше, тем дешевле и надёжнее совмещение.
Усреднённая точность сопоставления (MMA@ε, mean matching accuracy) — тот же CMR, посчитанный для ε = 1…10 px и усреднённый по парам снимков.

## Слайд 41

Метрики качества
Метрики точности совмещения
Mean Matching Error — среднее расстояние (в пикселях) между предсказанными и истинными положениями точек после применения найденного преобразования. Аналогично, можно посчитать MSE и RMSE.
Доля успешных совмещений (Success Rate@ε SR) — доля пар снимков, совмещённых с RMSE < ε (например, 3/5/10 px).

## Слайд 42

Метрики качества
Обратить внимание
1. Разметка сама неточна. Пары совмещены геопривязкой с какой-то остаточной ошибкой. Требовать точность лучше разметки бессмысленно
2. Размер галереи и похожие сцены. Соседние фрагменты одного снимка, а тем более однородные (поле, вода), сложно различить даже эксперту — Recall@1 падает не по вине модели.
3. Пороги и гиперпараметры подбираем на валидации, тест – только проверка.
4. Время и отказы. Метод с SR 95%, который считает пару минуту, для навигации БПЛА хуже метода с SR 90% за 50 мс. Время на пару и долю отказов (RANSAC не нашёл H) приводим наряду с метриками точности.
